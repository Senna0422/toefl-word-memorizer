# TOEFL Word Memorizer

A simple TOEFL word memorizer made while learning programming with AI tools.

Words are studied in groups of 10.
Users type the spelling from memory, and incorrect words are added to a review list for extra practice.

## ✨ Features

* 📚 Study TOEFL words in groups of 10
* ⌨️ Type words from memory
* ❌ Incorrect words go into a review list
* 🎯 Simple interface
* 🤖 Made with AI-assisted coding
